# Writing a course

A course is one JSON file in this directory. A server reads every `.json` here at boot (and again on `dr_reload`), checks it, and plays it; a file it refuses is listed by `dr_courses` with the reason, and every other course still plays. Clients never read these files: the server sends the course it is playing to each of them as the round begins.

The courses shipped here are generated by [`../tools/build_courses.py`](../tools/build_courses.py) and should be changed there, not here — `tools/build_courses.py --check` fails when a file is not what it would write. The builder is also the quickest way to write a new course: a course is a list of sections (`run`, `trapdoor`, `spike_walls`, `crusher`, `jaws`, `floor_spikes`, `falling`, `fire`, `blades`, `blocks`, `floes`, `roll`, and `hops`, a bunny-hop stretch with no trap) laid one after another, and the walls, the walkway and a button opposite every trap are laid for you. What follows is the format itself, for anything the sections do not do.

Every length is metres, every angle degrees, every time seconds. A position is `[x, y, z]`, and it is the **centre** of what it places unless a field below says otherwise. A course runs along **-Z**: the start is at the largest z and the end arena at the smallest.

## The document

```json
{
	"format": 1,
	"kind": "course",
	"id": "dr_my_course",
	"name": "My Course",
	"author": "you",
	"blurb": "One line, shown when the round begins.",
	"kill_height": -10.0,
	"round_seconds": 0,
	"theme": {"sky": [0.6, 0.7, 0.9], "horizon": [0.9, 0.9, 1.0], "void": [0.1, 0.1, 0.2],
		"sun": [1, 1, 1], "deck": [0.5, 0.6, 0.8], "fog": 0.006},
	"start": {"at": [0, 0, 5], "size": [6.5, 3, 6], "yaw": 0},
	"activators": {"at": [6.25, 3, 5], "size": [4, 3, 4], "yaw": 0},
	"finish": {"at": [0, 0, -98], "size": [6.5, 3, 3], "yaw": 0},
	"end": {
		"runners": {"at": [0, 0, -105], "size": [10, 3, 3], "yaw": 0},
		"activators": {"at": [0, 0, -124], "size": [10, 3, 3], "yaw": 180}
	},
	"pieces": [],
	"traps": [],
	"route": []
}
```

- `id` is lowercase a–z, 0–9 and `_`. A file whose id is `dr_practice` replaces the built-in practice course.
- `kill_height`: anybody below it is out. Put it under every pit.
- `round_seconds`: the most a round on this course lasts; 0 is the server's own (`dr_round_seconds`), and the server's is always the ceiling.
- `theme.deck` tints the ground and every trap floor, so a trapdoor looks like floor.
- **Areas** (`start`, `activators`, `finish`, and both ends of `end`): `at` is the middle of the area's FLOOR, `size` is width, height and depth, `yaw` is which way somebody put there faces (0 is -Z). The runners' start gets a gate across its front (its -Z edge) that holds them through the countdown. Crossing into `finish` sends a runner to `end.runners`; the first one also sends every activator to `end.activators`.

## Pieces

Still things, and the two kinds that move on their own:

| kind | fields | |
| --- | --- | --- |
| `box` | `at`, `size`, `yaw`? | Floor, walls, anything square. |
| `ramp` | `at`, `size`, `pitch`, `yaw`? | A box tilted: positive `pitch` raises its far (-Z) end. |
| `ball` | `at`, `radius` | |
| `cylinder` | `at`, `radius`, `height` | |
| `mover` | `from`, `to`, `size`, `period`, `phase`? | A platform sliding back and forth, eased at both ends. Carries whoever is on it. |
| `turntable` | `at`, `radius`, `speed` (°/s), `thickness`? | Carries whoever is on it. |
| `kill` | `at`, `size`, `look`? | A volume that kills anybody in it, always: the spikes in a pit, a pool. `look` is `spikes` (default), `liquid` or `none`. Never solid. |

Any piece takes `role` (`deck`, `pillar`, `cannon`, `arena`, `hazard`, `safe` — which prototype texture it is drawn with), `tint` (`[r, g, b]`), and a still piece takes `"visible": false` for a collider with nothing drawn: the clip above the runners' wall that keeps an activator out of the corridor while letting them see into it.

## Traps

```json
{
	"id": "my_trapdoor",
	"name": "Trapdoor",
	"button": {"at": [4.6, 3.0, -18.0], "yaw": 90},
	"cooldown": 0,
	"timing": {"delay": 0, "out": 0.25, "hold": 3.0, "back": 1.5},
	"victim": [1.4, 0.0, -18.0],
	"parts": [
		{"at": [-1.625, -0.25, -18], "size": [3.25, 0.5, 6],
			"turn": {"axis": "z", "degrees": -95, "pivot": [-3.25, -0.25, -18]}},
		{"at": [1.625, -0.25, -18], "size": [3.25, 0.5, 6],
			"turn": {"axis": "z", "degrees": 95, "pivot": [3.25, -0.25, -18]}}
	]
}
```

- `button.at` is the floor under the button; its top is a metre above it. An activator presses it with E from within `dr_button_reach` (2.2 m). Keep buttons at least 2.6 m apart, or an activator presses the one they did not mean.
- `cooldown`: 0 is once a round. Otherwise the seconds from one press until the next — and never while the trap is still out.
- `timing`: after the press the trap waits `delay`, goes out over `out`, stays out for `hold`, and comes back over `back`. A negative `hold` stays out for the rest of the round: a floor that falls and does not return.
- `victim`: where a runner stands to be caught by it. Nothing in a round reads it; `examples/headless_courses` stands somebody there, presses, and fails the trap if they live — or if they die before the press. Give every trap one.
- `zone`? (`{at, size}`): where somebody has to be for the trap to matter, for stand-in activators. Without it, the box every part sweeps, grown by a metre.

### Parts

Every part is a box (`at`, `size`, `yaw`?, `pitch`?) that moves, at full extension, by any of:

- `move`: `[x, y, z]`, added to its position;
- `turn`: `{axis: "x" | "y" | "z", degrees, pivot}`, a rotation about `pivot`;
- `spin`: degrees a second about its own up axis, while the trap is running.

And is one of:

- **solid** (the default for a part that does not kill): a floor. Whoever stands on it is carried with it — off a trapdoor that swings down, round a log that rolls, into the pool with a floe that sinks;
- **lethal** (`"lethal": true`, not solid unless `"solid": true` is given — and it should not be): anybody whose body touches the box dies. A lethal part that does not move is OFF until the trap runs and ON while it is out, and is only drawn then — fire.

`look` is how the box is drawn: `block` (default), `spikes` (points along `face`: `up`, `down`, `forward`, `back`, `left`, `right`), `blade` (a toothed disc — give it a `spin`), `fire`, `liquid`. The box is always what collides and kills; the look is only the picture. A part that is not lethal is drawn as floor unless given a `role`, because a trapdoor painted as a trapdoor is one every runner walks round.

## Route

The points a stand-in runner follows, in order. `{"at": [x, y, z]}` is a point to run to; `"jump": true` makes it a **landing** — the stand-in runs toward it and jumps wherever the floor ahead ends. `reach` (1.2) is how close counts as there, `walk` and `crouch` hold those keys on the way. Stand-in activators need no route: they walk straight along the walkway, so keep the walkway straight.

## Checking it

```bash
godot --headless --path . res://examples/headless_courses.tscn
godot --headless --path . res://tools/trace_run.tscn -- --course=dr_my_course --every=0.25
tools/shot.sh --view=course --dr-course-ids=dr_my_course
```
